# Data and asset provenance

- Match events, fictional rosters and illustrative season baselines are generated by `backend/matchlens/synthetic.py`. They contain no redistributed Premier League match feed or real European player rankings.
- Pitch/scene visuals are repository SVG/React rendering of the fictional event state. No match footage, photographs, club crests or trained recognition model are bundled.
- Icons use the declared `lucide-react` dependency. React and other dependencies retain their own licenses; consult installed package metadata and the lockfiles. This document does not relicense dependencies.
- CSS optionally requests DM Sans and Manrope through Google Fonts. System-font fallbacks are provided; these are external font requests rather than bundled font files.
- The walkthrough uses captures of this local application, with explanatory captions. It is an edited screenshot walkthrough rather than continuous live footage.
