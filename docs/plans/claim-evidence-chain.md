# Claim-grounded evidence chain

User-approved scope: improve existing recommendation roles and evidence trail together. Three stateless role agents using the existing provider: evidence_analysis, conclusion, checker. No new infrastructure/framework claims. Existing legacy specialist remains an explicitly historical comparator; evidence_chain is the new recommendation policy.

1. Build one deterministic, selected-clock/source-revision-bound ledger. Every candidate has typed facts (subject, predicate, value, unit/scope, exact event revisions), allowed meaning and limitation, and publishable canonical claim cards. Separate the selected sequence from aggregate-stat sources.
2. Evidence analyst selects relevant eligible candidate/fact IDs and optional contrary evidence. Conclusion agent chooses a supported conclusion from that selection; it cannot substitute numbers/subjects or inject prose. Meaning comes from the approved editorial interpretation attached to calculated evidence, not unrestricted speculation.
3. Checker receives the expanded proposed claims and facts, checks support/relevance/clock/uncertainty for every claim, and can veto. Its judgment is not independent proof; deterministic contracts and canonical fact rendering remain the publication boundary. Three model calls maximum; each actual call consumes request budget. Timeout, malformed IDs, missing checks, disagreement and source revision changes preserve useful local fallback.
4. Public local mode has the same ledger but explicitly zero agent calls. Add per-claim supporting sequences, calculation definitions, event revisions and counter-evidence to UI; show primary sequence count instead of the entire match's source count. Aggregate sources stay inspectable separately. Display stage statuses, not hidden reasoning.
5. Regression tests cover subject/metric substitution, unknown facts/conclusions, checker gaps/rejection, future clocks, changed revisions, budget exhaustion, event corrections and focused evidence counts. Controlled actual Foundry run/evaluation records every handoff/call/usage without claiming multi-agent superiority. Keep public paid model calls disabled.

Acceptance: every published claim maps to eligible ledger facts and exact source events or a named editorial rule; checker approval cannot override deterministic contract violations. Primary evidence matches the displayed sequence. No claim that three prompts imply independence, reliable semantics, Agent Framework integration or lower cost.
